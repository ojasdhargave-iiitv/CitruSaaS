## Reporting a Vulnerability

Security is a primary concern for **CitruSaaS**. We take vulnerabilities and potential security issues very seriously.

If you discover a security vulnerability within CitruSaaS, please send an e-mail to the maintainers rather than reporting it via a public GitHub issue. 

**Steps to report:**
1. Send an email with the subject `[SECURITY VULNERABILITY]` with your findings.
2. Outline the steps to reproduce the vulnerability.
3. Keep the information confidential until a patch is released to the community.

You should receive an acknowledgment within 48 hours, and a follow-up assessment within 1 week outlining our timeline for mitigation.

*Thank you for taking the time and effort to improve the security of our application!*
